# Hook patterns for the first 30 seconds (H1-H10)

The hook's job: **confirm the click, raise the stakes, open a loop.** It continues
the title/thumbnail; it never re-introduces the channel.

| # | Pattern | Structure | Pairs with |
|---|---|---|---|
| H1 | Result first | Show the end state in 3-5 s, then "here is how" | T1, T7, T12 |
| H2 | Cold open in the action | Start mid-scene, explain later | T7, T11 |
| H3 | The stakes | What the viewer loses if they get this wrong (a real number) | T3, T8 |
| H4 | Promise + proof | "By the end you'll [outcome]. I've done it [receipt]." | T2, T9 |
| H5 | Myth flip | State the belief, break it with one fact | T5, T8, T13 |
| H6 | Direct question | Ask the viewer's own question, promise a direct answer | T14, T6 |
| H7 | Countdown tease | "Number 1 surprised me" (only if it really is surprising) | T4, T10 |
| H8 | Personal confession | Short, specific, vulnerable moment with a date | T12, T8 |
| H9 | Visual contrast | Before/after or A vs B on screen, no talking for 2 s | T6, T12 |
| H10 | Path preview | 3 fast cuts of what is coming, each a mini-payoff | T11, T4 |

## Hook checklist

- [ ] First spoken line ≤ 12 words and continues the title, not "hello".
- [ ] The promise of the title is restated or shown by 0:10.
- [ ] One reason to stay to the end (open loop) is planted by 0:30.
- [ ] No intro animation > 3 s, no sponsor before the hook, no "subscribe" ask in the hook.
- [ ] Visual change at least every 5-8 s in the first 30 s (cut, zoom, b-roll, text).
