# Script structures by format

Times are for a ~10 min video; scale proportionally.

## Tutorial / how-to
1. **0:00 Hook** — show the finished result (H1) or the cost of doing it wrong (H3)
2. **0:20 Promise + path** — "3 steps, the third is where most people fail" (open loop)
3. **0:40 Step 1** — why → how → proof on screen
4. **Step 2** — same pattern; re-hook before step 3
5. **Step 3 / the hard part** — closes the open loop
6. **Common mistakes** (fast, 3 items)
7. **Hand-off** — "if you got stuck at X, watch this next" → end screen

## Test / challenge / experiment
1. **Hook** — the stakes + the constraint (H2 cold open in the action)
2. **Rules** — 20 s max, on-screen text
3. **Attempt 1** — what happened, real number
4. **Twist** — something breaks (re-hook)
5. **Attempt 2 / adjustment**
6. **Result** — the number, compared with the expectation
7. **What I'd tell you to do** — the transferable lesson → next video

## Story / case study
1. **Cold open at the most tense moment**
2. **Rewind** — "three months earlier..." context in 30 s
3. **Rising stakes** — each beat raises the cost of failure
4. **Turning point** — specific date, specific decision
5. **Outcome** — receipts
6. **Lesson** — one, said plainly
7. **Hand-off**

## List / ranking
1. **Hook** — the most surprising item teased (H7), not revealed
2. **Criteria** — how you ranked (15 s, builds trust)
3. **Items from weaker to stronger**, each: what, why it's here, who it's for
4. **#1** — closes the tease
5. **Which to pick** — decision rule by viewer type → next video

## Comparison (A vs B)
1. **Hook** — the decisive difference nobody mentions (H5) or the visual contrast (H9)
2. **Who this is for** — 10 s
3. **Round-by-round**: 3-5 criteria, winner per round on screen
4. **Surprise round** — the criterion that flips the result for some viewers
5. **Verdict by viewer type**

## Short (≤ 60 s default)
1. **0-1 s** — visual + line that is the payoff or the stakes
2. **1-45 s** — one idea, fast cuts, captions burned in
3. **Last 3 s** — payoff; last line loops into the first if possible
No intro, no subscribe ask, no "part 2" unless part 2 exists.
