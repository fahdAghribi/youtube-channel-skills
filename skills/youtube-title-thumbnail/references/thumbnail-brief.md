# Thumbnail brief template

```
CONCEPT:       [Result | Contrast | Emotion | Object | Curiosity]
FOCAL SUBJECT: [one thing the eye lands on first]
FACE:          [yes/no; expression: shock, doubt, joy, focus...; eyes toward the subject]
BACKGROUND:    [simple, blurred, solid colour; contrasts with subject]
TEXT:          [≤ 4 words, or none] font: [bold sans], position: [top-left]
COLOURS:       [2-3; one accent that pops against YouTube's white/dark UI]
COMPOSITION:
  +----------------------------------+
  | TEXT          |                  |
  |               |   [SUBJECT]      |
  |   [FACE]      |                  |
  |               |          [free]  |
  +----------------------------------+
AVOID:         [clutter, small text, bottom-right elements, repeating the title]
IMAGE PROMPT:  [optional, for generative tools]
```

## Composition rules

1. **One idea.** If you need to explain it, it is two thumbnails.
2. **Rule of thirds**; face on one side, subject on the other.
3. **Contrast**: subject vs background in both brightness and colour.
4. **Scale**: the focal element fills 30-50% of the frame.
5. **Text**: ≤ 4 words, adds what the image cannot say (a number, a stake), never the title.
6. **Test at 160×90**: shrink it; if you can't tell what it is, simplify.
7. **Dark & light mode**: avoid pure white or pure black edges that disappear into the UI.
8. **Series consistency**: same layout family per pillar so subscribers recognise it.

## Concept types

- **Result**: the end state (finished build, the number, the transformation)
- **Contrast**: before/after, A vs B, cheap vs expensive
- **Emotion**: a genuine reaction to something visible in the frame
- **Object**: one striking object, huge, on a clean background
- **Curiosity**: something visibly wrong or unusual that the video explains
