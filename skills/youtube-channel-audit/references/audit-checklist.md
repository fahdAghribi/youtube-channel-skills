# Channel audit checklist

Score each area 0-3. 0 = missing, 1 = present but weak, 2 = solid, 3 = a strength.

## 1. Positioning
- 0: no clear topic, videos jump between unrelated subjects
- 1: a topic, but no viewer or outcome ("tech videos")
- 2: topic + viewer ("tech for students")
- 3: topic + viewer + outcome, and 80%+ of the last 20 videos serve it

## 2. Audience fit
- Titles use the viewer's search phrasing (check 5 titles against YouTube search autocomplete)
- Comments come from the intended viewer (job, level, language)
- Adjacent channels named by the user actually overlap (same viewer)

## 3. Pillars
- Count distinct series/topics in the last 20 uploads
- For each pillar: median views vs channel median; at least one 2x+ outlier
- Flag pillars that never beat 0.5x the channel median for 5+ videos (candidates to drop)

## 4. Packaging
- Thumbnail consistency: would a subscriber recognise the channel in a grid without reading the name?
- Thumbnail legibility at 160 px: ≤ 4 words, one focal point, high contrast
- Title + thumbnail complement (no repeated words)
- Titles within ~60 chars for browse topics

## 5. Retention craft (needs data)
- Avg % viewed per video vs channel norm
- 0:30 retention on the 3 most recent long-form videos (target 65-80%)
- Intro length before the first value beat (target < 15 s)

## 6. Cadence
- Uploads per week over the last 12 weeks; gaps longer than 3 weeks
- Does the user's weekly time budget match the cadence? If not, recommend fewer, better videos

## 7. Channel page
- Banner: key text inside the 1546×423 safe area, readable on mobile
- Handle set and matches the brand
- About: first sentence = promise; includes keywords; links (site, newsletter, contact)
- Trailer for non-subscribers (30-90 s) and featured video for returning subscribers
- Home sections: one per pillar + "start here" playlist
- Playlists: each pillar has a playlist ordered as a watch path

## 8. Conversion
- End screens on every long-form video (best-for-viewer + subscribe)
- Pinned comment with a question or next step
- Description: top lines value, then links, then chapters
- Links match the stated goal (lead magnet for leads, product for sales, nothing for pure growth)
